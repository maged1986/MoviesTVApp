# 📺 Movies TV App - Android TV Implementation

**Movies TV App** is a specialized Android application designed for big-screen experiences. It demonstrates a deep understanding of **Android TV development**, focusing on smooth navigation, 10-foot UI design, and high-performance media browsing.

---

## 🚀 Key Features

- **Big Screen Optimization:** Designed specifically for Android TV using the **Leanback Library** and **Jetpack Compose**.
- **DPAD Navigation:** Optimized for remote control interaction, ensuring a seamless user experience.
- **Content Discovery:** Browse movies and TV shows categorized by genre with smooth horizontal and vertical scrolling.
- **Detailed Metadata:** Rich detail screens showing movie descriptions, ratings, and cast information.
- **Offline Caching:** Powered by **Room Database** to allow browsing previously loaded content without an internet connection.

---

## 🛠 Tech Stack

- **Language:** [Kotlin](https://kotlinlang.org/) - 100%
- **TV Frameworks:** [Leanback Library](https://developer.android.com/training/tv/playback/leanback) & **Jetpack Compose for TV**.
- **Architecture:** MVVM (Model-View-ViewModel).
- **Asynchronous Programming:** [Coroutines](https://kotlinlang.org/docs/coroutines-overview.html) & [Flow](https://kotlinlang.org/docs/flow.html).
- **Networking:** [Retrofit](https://square.github.io/retrofit/) for consuming Movie APIs (TMDB/custom).
- **Local Storage:** [Room Persistence Library](https://developer.android.com/training/data-storage/room).
- **Image Loading:** [Coil](https://coil-kt.github.io/coil/) or [Glide](https://github.com/bumptech/glide) for optimized TV rendering.

---

## 🏗 TV Development Highlights

As a **Senior Developer**, I focused on solving common TV-specific challenges in this project:
- **Focus Management:** Handling complex focus transitions between rows and columns.
- **Performance:** Optimizing image memory usage for low-spec TV hardware.
- **UI Consistency:** Implementing the 10-foot UI guidelines to ensure readability from a distance.
